# Hide Background Apps

A GNOME Shell extension that hides the Background Apps item in the Quick Settings menu.

Background apps keep running as usual, only the menu item is hidden.

## Compatibility

Supported GNOME Shell versions: 45, 46, 47, 48, 49, 50, 51.
